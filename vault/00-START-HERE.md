# وثاق — ذاكرة الفريق المشتركة

هذا المجلد هو مرجع الفريق داخل Git. يصل مع كل clone وbranch وcommit؛ لا يعتمد على سجل محادثة شخص واحد. يمكن فتحه مباشرة في GitHub أو محرر Markdown أو كـVault في Obsidian؛ لا إضافات مطلوبة.

## قبل أي فرع أو مهمة

1. اقرأ [السياق](01-CONTEXT.md) و[الحالة الفعلية](02-STATUS.md).
2. راجع [قرارات التنفيذ](07-DECISIONS.md) و[آخر تسليم](08-HANDOFF.md).
3. اختر بطاقة من [Backlog](06-BACKLOG.md)، سجّل اسمك كمالك، وأعلن الفرع في التسليم.
4. راجع [Sprint الحالي](sprints/S01-FOUNDATION.md) وشروط قبوله.
5. شغّل baseline الاختبارات قبل التعديل. افصل الفشل السابق عن الفشل الناتج عن تغييرك.
