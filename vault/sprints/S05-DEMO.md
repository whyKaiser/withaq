# S05 — تسليم العرض

8 أكتوبر 2026. الحالة: PLANNED. البطاقات WQ-021/022. المالك: غير مسند.

الهدف: يستطيع عضو آخر أو حكم إعادة تشغيل المصدر وفهم ما يثبت وما لا يثبت.

القبول: clone نظيف، locks ناجحة، دليل تشغيل ومقطع عرض إن سُجل، evidence مطابق لنفس commit، release notes بالمنجز والقيود، قائمة المهام المفتوحة، وعدم تضمين أسرار أو ادعاءات مختبر غير مختبرة.

المراجعة النهائية يشارك فيها عضو لم يكتب الجزء المعروض. لا يساوي موعد التسليم موافقة تلقائية على الجاهزية؛ سجّل النطاق الذي اجتاز القبول فعلًا.
