# مراحل المشروع وبوابات الخروج

المراحل تصف قدرات المنتج؛ Sprints تحدد متى نحاول تسليمها. قد يمتد Sprint عبر مرحلة أو يمتد تنفيذ مرحلة بعد 8 أكتوبر.

| المرحلة | نطاقها | بوابة القبول | الحالة الآن |
|---|---|---|---|
| P0 — سياق وبيئة | repo، vault، locks، هوية تطوير | clone جديد يستطيع البناء والاختبار | تنفيذ أساسي؛ تحقق التسليم في HANDOFF |
| P1 — قرار محدود مستقل | عقود، snapshot، MFSC، validator | oracle + empty plan + timeout + tampering | محاكاة منفذة؛ اختبارات أولية ناجحة |
| P2 — سلطة الحالة والبيانات | PostgreSQL، lineage عام، barriers، workers | لا نشر متأخر بعد السحب، leases آمنة، restart | fixture/SQLite فقط؛ الجزء الموزع متبقٍ |
| P3 — إفصاح وتكامل | exact-byte approval، gateway، UI | منع التجاوز، unknown-send، رحلة كاملة | بوابة mock وواجهة أولية؛ فصل الخدمات متبقٍ |
| P4 — مختبر شبكة | VM، nftables، sessions، probes | حجب حزم فعلية واستمرار كل عقد موثّق | لم يبدأ؛ خارج المحاكاة |
| P5 — تأهيل وعرض | reproducibility، restore، benchmark، دليل الحكام | تشغيل مستقل من عضو ثانٍ + أدلة خام + حدود | جارٍ تجهيز الأدلة؛ ليس مكتملًا |

الهدف الأقرب 8 أكتوبر: عرض محاكاة متكامل ومصدر قابل للتشغيل ونتائج اختبارات صادقة. محاولة إكمال باقي المخطط تستمر حسب اجتياز البوابات؛ الموعد لا يلغي شروط القبول.
