# تشغيل وإيقاف المحاكاة

1. نفذ bootstrap من README مرة أولى أو عند تغيّر lock.
2. شغّل `scripts/serve.py` ببايثون البيئة الافتراضية.
3. افتح `http://127.0.0.1:8000`، ثم انسخ token من `data/local-access.txt` إلى الصفحة. يبقى في الذاكرة فقط، ولا يوضع في VITE_* أو Git.
4. أنشئ تجربة، وافحص القرار قبل تطبيقه. أزرار السحب والاستعادة تخص بيانات اصطناعية محلية.
5. أوقف باستخدام Ctrl+C. العودة بنفس المجلد تحفظ SQLite والأحداث. هذا ليس اختبار تعافي worker.

## تشخيص سريع

| العلامة | المعنى والخطوة |
|---|---|
| 401 | token مفقود/خاطئ؛ انسخ token من بيئتك الحالية |
| 403 ROLE_DENIED | viewer حاول تعديلًا؛ استخدم هوية operator المخولة |
| 409 STALE_SNAPSHOT | نسخة التجربة تغيرت؛ أعد تحميل حالتها أو أنشئ تجربة جديدة؛ لا تتجاوز الفحص |
| 403 ROOT_REVOKED | الحاجز يعمل؛ لا تُعد المصدر ACTIVE لحل المشكلة |
| UNKNOWN | أدلة ناقصة أو مهلة؛ ليس نجاحًا ولا إثبات استحالة |
| OUTCOME_UNKNOWN | لا retry أعمى؛ استخدم تجربة جديدة لفحص الحالة الأخرى |
| / يعيد 404 | ابنِ الواجهة ثم أعد تشغيل الخدمة |
| 503 readiness | تحقق من تهيئة token وإمكانية فتح قاعدة البيانات |
| المنفذ 8000 مشغول | أوقف النسخة السابقة التي تعرف أنها تخص وثاق؛ لا تقتل عملية مجهولة |
| npm ECONNRESET أو مهلة تنزيل | أعد npm ci بعد تحسن الاتصال؛ cache محلي مطابق للـlock يصلح لإعادة التثبيت. لا تعطل التحقق من TLS |

قاعدة البيانات والرموز في `data/` ليست قابلة للنشر. لنسخة احتياطية محلية أوقف التطبيق أولًا ثم انسخ المجلد إلى مكان موثوق؛ اختبار استعادة مؤهل ضمن WQ-020 وليس منجزًا بعد. لا حذف تلقائيًا أثناء bootstrap أو restart.
