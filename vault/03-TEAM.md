## تقسيم مقترح لستة مسارات

1. **التكامل ومالك المنتج:** نطاق العرض، الأولويات، قبول المخرجات وتجميع الإصدار.
2. **العقود والتخطيط:** snapshots، MFSC، حالات تعارض الوظائف وحدود المهلة.
3. **التحقق والاختبارات:** oracle مستقل، اختبارات العبث والنسخ والقبول؛ مراجع مختلف عن مؤلف planner.
4. **الحالة والبيانات:** PostgreSQL، lineage، revocation، recovery، outbox.
5. **الإفصاح والتشغيل:** approvals، gateway، worker، المختبر المعزول والأدلة.
6. **الواجهة والعرض:** العربية/الإنجليزية، تجربة الحكام، رسائل الخطأ وإخراج الأدلة.

الأسماء لا تُربط بمسارات دون اتفاق الفريق. كل بطاقة لها مالك واحد ومراجع مختلف. العضو يستطيع امتلاك أكثر من بطاقة؛ لا يعمل شخصان على البطاقة نفسها دون تنسيق. لا توجد دعوات GitHub مرسلة أو CODEOWNERS لحسابات مخمّنة.
