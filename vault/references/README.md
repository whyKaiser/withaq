# المرجع والتحكم بالإصدارات

- [الدليل العربي](WITHAQ_Complete_Build_Operations_AR.pdf)
- [الدليل الإنجليزي](WITHAQ_Complete_Build_Operations_EN.pdf)

الإصدار 2.0، 28 سبتمبر 2026، 62 صفحة. وفّرهما صاحب المشروع في 3 أكتوبر لبناء المشروع وسياق الفريق. هما مخطط ومصدر للمتطلبات، وليسا نتائج تنفيذ. التعليمات البشرية الأحدث تقرر الأولوية؛ أمثلة المستند لا تمنح صلاحية نشر بيانات أو تنفيذ أوامر مدمرة.

الأرقام المرجعية الأكثر استخدامًا: ص18 خوارزمية MFSC، ص19 المثال، ص20 التحقق والتنفيذ، ص22–23 السحب والإفصاح، ص30 API، ص31–40 البدء والتشغيل، ص43 رحلة العرض، ص44 AT01–AT12، ص48–58 مخطط الملفات، ص59 D1–D7.

الملصق المُسلّم في `docs/` منفصل عن حالة التنفيذ الحالية. أي تحديث للمرجع يحتاج تاريخًا وسببًا وتحديث Backlog؛ لا تستبدل الملف بصمت.
